# Лендинг-портфолио Frontend Developer

Небольшой персональный лендинг, выполненный в рамках тестового задания.

Проект представляет собой адаптивную страницу-портфолио с краткой информацией обо мне как о frontend-разработчике.

Основная цель проекта — показать подход к frontend-разработке, организацию структуры приложения, работу с API и использование AI-инструментов в процессе разработки.

## Как реализована форма обратной связи

Форма содержит поля:

- Имя
- Телефон
- Email
- Комментарий

После отправки:

- письмо отправляется владельцу сайта
- пользователю должна отправляться копия, если зарегистрировать домен и верифицировать его в Requestly. Без этого копия будет отправляться только если письмо у владельца
- отображается статус:
  - loading
  - success
  - error

### Валидация

Используется:

- React Hook Form
- Zod schema validation

Проверяется:

- обязательность полей
- минимальная длина
- корректный email

## Serverless API

Форма работает через Vercel Function:

```bash
/api/contact
```

Алгоритм:

1. Принимается POST запрос
2. Проверяется метод
3. Выполняется rate limit
4. Проверяется honeypot поле
5. Валидируется body через Zod
6. Отправляется письмо владельцу
7. Отправляется письмо пользователю

---

## Email delivery

Email delivery реализован через Resend API.

Для тестового деплоя используется sandbox sender:

```txt
onboarding@resend.dev
```

Это позволяет протестировать отправку писем без покупки собственного домена.

Для production-использования можно подключить собственный домен и настроить:

- SPF
- DKIM

Это позволить отправлять копию письма пользователю и использовать свой email sender.

## Защита формы

Реализовано:

### Honeypot

Скрытое поле:

```txt
company
```

Используется для отсечения простых ботов.

---

### Rate limiting

Ограничение количества запросов на один IP.

Возвращается:

```http
429 Too many requests
```

при превышении лимита.
